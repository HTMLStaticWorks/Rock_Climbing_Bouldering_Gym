Progression Guide

Your Climbing Journey

Map your ascension journey from day one through our structured grade levels and coach-designed checkpoints.

Step 1 V0 - V2

Beginner

Learn basic footwork, hand holds (jugs, crimps), and essential safety procedures using auto-belays. This step focuses on establishing body balance and orientation on the wall.

Key Focus Checklist

Basic footwork placement
Auto-belay certified
Identifying hold types
Safety and falling technique

Target Skill Metrics

Finger Strength30%
Core Tension / Balance60%
Endurance40%
Start Training
Step 2 V3 - V5

Intermediate

Master dynamic movements, drop-knees, route-reading tactics, and initiate standard lead-climbing safety checks. Start focusing on more complex pathing.

Key Focus Checklist

Drop-knees & flags
Dynamic movements
Lead-climbing checks
Beta reading / route planning

Target Skill Metrics

Finger Strength55%
Core Tension / Balance70%
Endurance60%
Start Training
Step 3 V6 - V8

Advanced

Train climbing-specific core tension, contact strength on micro-crimps, and complex dynamic beta configurations. You'll work with coaches on targeted fingerboard training.

Key Focus Checklist

Micro-crimp contact strength
Board climbing mastery
Fingerboard hanging sessions
Complex dynamic beta

Target Skill Metrics

Finger Strength75%
Core Tension / Balance80%
Endurance75%
Start Training
Step 4 V8 - V10

Competition Athlete

Develop lightning-fast route adaptations, high-intensity endurance blocks, and psychological competition preparation routines under simulated tournament pressure.

Key Focus Checklist

Fast route adaptation
Comp-style slab coordinates
High-intensity lead endurance
Psychological pressure prep

Target Skill Metrics

Finger Strength85%
Core Tension / Balance90%
Endurance85%
Start Training
Step 5 V10+

Elite Level

Push limits on custom overhung boards, log competitive results nationally, and participate in pro-level setting workshops with international setting crews.

Key Focus Checklist

Overhung board mastery
National competitive logging
Pro-level setting workshops
High-risk dynamics

Target Skill Metrics

Finger Strength98%
Core Tension / Balance98%
Endurance95%
Start Training
